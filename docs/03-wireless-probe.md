# 无线仿真器：品牌、配对与接线

## 设备简要说明

依据用户提供的[《HS/FS 高速无线 DAPLINK 仿真器使用说明书》](../reference/wireless-daplink-manual.pdf)：

| 项目 | 说明 |
| --- | --- |
| 厂家 | 商丘爱博电子科技有限公司，Shangqiu Aibo Electronic Technology Co., Ltd. |
| 品牌与产品标识 | 封面产品机身印有 Horco、DAP_WL；封面公司标识为 ABorobots |
| 产品系列 | HS/FS 高速无线 DAPLink，具体版本以实物为准 |
| FS / HS | 说明书记载 FS 使用 CH32V208，HS 使用 CH32V208 + CH32V305 |
| 无线结构 | 电脑侧 master 与目标侧 slave 配对，使用设备自身的无线链路 |
| 调试功能 | 支持 SWD、JTAG、硬件/软件复位；另提供虚拟串口 |
| 有线模式 | 普通模块可切换 usb 模式；Mini FS 仅作为主机使用 |
| 软件支持 | 说明书列出 Keil、VS Code、Ozone 等支持 DAPLink 的软件 |
| Windows 驱动 | 说明书称 Windows 10 及以上配对后即插即用，无需另装驱动 |

“仿真器”在这里是硬件调试探针，不是软件模拟 STM32。无线替代的是电脑与目标板之间的长调试线；目标侧从机仍需通过短线连接 STM32。

本文不把厂家宣传的距离或下载速度作为本项目实测结果，也不推断用户手上一定是哪种 HS/FS 组合。

## 实际连接链路

```text
电脑 VS Code / OpenOCD
        │ USB
无线主机 master（蓝灯）
        ))) 设备自身的无线链路 (((
无线从机 slave（绿灯）
        │ SWD 短线
      STM32F103
```

无需电脑蓝牙配对、Wi-Fi 路由器或 HC-05。工程中的 HC-05 蓝牙是另一条遥测/手机控制链路。

## 配对方式一：按键

按说明书第 8 页：

1. 第一个普通模块按住 B 键上电，约 2 秒后松开，进入紫灯慢闪。
2. 第二个普通模块同样按住 B 键上电，约 2 秒后松开。
3. 配对后两端分别成为蓝灯主机和绿灯从机。
4. 两端重新上电；蓝灯端接电脑 USB，绿灯端放在目标板旁。

Mini FS 的使用范围与普通模块不同，按对应实物说明操作。

## 配对方式二：修改 U 盘配置

各模块连接电脑后会显示 U 盘，打开其原有 `CONF.TXT`，保留其他字段并修改所需项目。下面采用说明书第 4 页展示的分节格式；同步字只是示例，两端需要相同且避免与附近其他套设备重复。

主机：

```ini
[base]
mode=master
addr=59e59d9c
[advanced]
rate=2M
esp_down=disable
```

从机：

```ini
[base]
mode=slave
addr=59e59d9c
[advanced]
rate=2M
esp_down=disable
```

保存后重新上电。模式值为小写，速率值为 `2M`、`1M`、`500K`、`125K` 之一，两端保持一致。这里的空中速率与 OpenOCD 的 SWD 时钟是两个独立参数。

说明书第 8 页把 `master` 写成了 `mester`；本文依据第 4 页截图和第 5 页参数表使用 `master`。

本教程只做 STM32 SWD 调试，因此示例关闭 `esp_down`。说明书说明该功能会复用 RST/TDI 为串口下载控制信号，可能干扰 JTAG 和硬件复位。需要 ESP 下载时应另按厂家说明配置。

## 指示灯与模式

| 指示状态 | 含义 |
| --- | --- |
| 红色 | usb 有线模式，出厂默认模式 |
| 蓝色 | master 无线主机 |
| 绿色 | slave 无线从机 |
| 黄色 | 按 A 键进入的模式设置状态 |
| 紫色慢闪 | 按 B 键上电后的配对状态 |

若要手动切换模式：长按 A 至黄灯，短按 A 选择模式，再长按 A 保存，重新上电。

## 从机与 STM32F103 接线

| 从机信号 | STM32F103 信号 |
| --- | --- |
| SWDIO / TMS | PA13 / SWDIO |
| SWCLK / TCK | PA14 / SWCLK |
| GND | GND |
| RST（可选） | NRST；本仓库默认配置不依赖该线 |

从机与目标板都需要供电，并且共地。说明书第 8 页图中还连接了两端 `3V3`；供电方向、电流能力及是否允许与板上电源并联应按实物说明确认，避免把两个供电输出直接并接。本教程不据此推断 5V/3V3 引脚的输出能力。

在 CubeMX 的 SYS 中保留 Serial Wire，使 PA13/PA14 用于调试；不要让应用初始化覆盖它们。引脚编号只适用于本例 STM32F103，其他芯片应查对应引脚表。
